# 📂 Module 2.2: 반복문 (Iteration)

## 1. while 루프
조건이 참(`True`)인 동안 계속해서 코드를 실행합니다.

```python
count = 1
while count <= 3:
    print(f"반복 횟수: {count}")
    count += 1
```

## 2. for 루프와 range()
정해진 횟수나 시퀀스(리스트, 문자열 등)의 요소를 하나씩 순회합니다.

```python
# 0부터 4까지 출력
for i in range(5):
    print(i)

# 문자열 순회
for char in "DNA":
    print(char)
```

## 3. 흐름 제어 키워드
- `break`: 루프를 즉시 종료
- `continue`: 다음 반복으로 건너뜀
- `pass`: 아무 작업도 하지 않음 (구조 유지용)
