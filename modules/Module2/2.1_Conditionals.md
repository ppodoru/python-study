# 📂 Module 2.1: 조건문 (Conditional Branching)

## 1. if, elif, else 구조
프로그램의 흐름을 조건에 따라 분기합니다.

```python
score = 85

if score >= 90:
    print("Grade: A")
elif score >= 80:
    print("Grade: B")
else:
    print("Grade: C")
```
**[실행 결과 예측]**: `Grade: B`가 출력됩니다.

## 2. 중첩 조건문
조건문 안에 또 다른 조건문을 넣어 더 세밀한 판단을 할 수 있습니다.

```python
is_enrolled = True
has_id_card = False

if is_enrolled:
    if has_id_card:
        print("입장 가능")
    else:
        print("학생증이 필요합니다.")
else:
    print("등록되지 않은 학생입니다.")
```
