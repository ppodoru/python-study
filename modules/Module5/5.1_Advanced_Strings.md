# 📂 Module 5.1: 문자열 심화 (Advanced Strings)

## 1. 문자열 포맷팅
```python
name = "Ghent"
version = 3.11

# f-string (권장)
print(f"Welcome to {name} Univ. Python {version}")
```

## 2. 주요 메서드
- `.split()`: 문자열 나누기
- `.join()`: 리스트를 문자열로 합치기
- `.strip()`: 공백 제거
- `.replace()`: 문자열 치환
