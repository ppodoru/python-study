# 📂 Module 5.2: 정규 표현식 (Regular Expressions)

## 1. re 모듈
복잡한 문자열 패턴을 찾거나 검증할 때 사용합니다.

```python
import re

text = "My student ID is 20261234"
match = re.search(r"\d{8}", text) # 숫자 8개 찾기
if match:
    print(f"찾은 학번: {match.group()}")
```

## 2. 메타 문자
- `\d`: 숫자
- `\w`: 문자+숫자
- `^`: 시작, `$`: 끝
- `*`: 0회 이상, `+`: 1회 이상
