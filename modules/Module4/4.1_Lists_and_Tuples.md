# 📂 Module 4.1: 리스트와 튜플 (Lists & Tuples)

## 1. 리스트 (List)
순서가 있고 변경 가능한 데이터 모음입니다. `[]`를 사용합니다.

```python
dna_bases = ["A", "C", "G", "T"]
print(dna_bases[0])    # 인덱싱: 'A'
print(dna_bases[1:3])  # 슬라이싱: ['C', 'G']

dna_bases.append("U")  # 요소 추가
```

## 2. 튜플 (Tuple)
순서는 있지만 변경 불가능한 데이터 모음입니다. `()`를 사용합니다.

```python
coordinates = (51.0543, 3.7267) # 겐트의 위도, 경도
```

## 3. 리스트 내포 (List Comprehension)
효율적으로 리스트를 생성하는 파이썬다운 방식입니다.

```python
squares = [x**2 for x in range(5)] # [0, 1, 4, 9, 16]
```
