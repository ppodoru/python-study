# 📂 Module 4.2: 딕셔너리와 집합 (Dictionaries & Sets)

## 1. 딕셔너리 (Dictionary)
Key-Value 쌍으로 데이터를 저장합니다. `{}`를 사용합니다.

```python
student = {
    "name": "Alice",
    "id": "20261234",
    "major": "Informatics"
}
print(student["name"]) # 'Alice'
```

## 2. 집합 (Set)
중복을 허용하지 않고 순서가 없는 모음입니다.

```python
my_set = {1, 2, 2, 3} # {1, 2, 3}
```
