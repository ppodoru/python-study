## 1. 클래스와 객체
- **클래스(Class)**: 붕어빵 틀 (설계도)
- **객체(Object)**: 붕어빵 (실체)

```python
class Student:
    def __init__(self, name, id):
        self.name = name # 인스턴스 변수
        self.id = id

    def study(self): # 메서드
        print(f"{self.name} 학생이 공부를 합니다.")

s1 = Student("Alice", "20261234")
s1.study()
```
