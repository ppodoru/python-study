# 📂 Module 7.2: 데이터 시각화 기초 (Basic Visualization)

## 1. Matplotlib 활용
데이터를 그래프로 시각화합니다.

```python
import matplotlib.pyplot as plt

x = [1, 2, 3, 4]
y = [10, 20, 25, 30]

plt.plot(x, y)
plt.xlabel("Time")
plt.ylabel("Growth")
plt.title("Experimental Result")
plt.show()
```
