## 1. 파일 읽기와 쓰기
`with` 구문을 사용하면 파일을 자동으로 닫아주어 안전합니다.

```python
# 쓰기
with open("test.txt", "w") as f:
    f.write("Hello Ghent!")

# 읽기
with open("test.txt", "r") as f:
    content = f.read()
    print(content)
```
