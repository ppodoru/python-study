# 📂 Module 6.2: 예외 처리 (Error Handling)

## 1. try-except 블록
에러가 발생해도 프로그램이 멈추지 않게 합니다.

```python
try:
    result = 10 / 0
except ZeroDivisionError:
    print("0으로 나눌 수 없습니다.")
finally:
    print("계산을 시도했습니다.")
```
