# 📂 Module 1.1: 프로그래밍 입문 (Introduction)

## 1. 알고리즘의 개념
알고리즘은 어떤 문제를 해결하기 위해 정해진 일련의 절차나 규칙입니다. 요리 레시피나 가구 조립 설명서와 비슷합니다.

### 알고리즘의 조건
- **입력**: 0개 이상의 입력이 있어야 함
- **출력**: 적어도 1개 이상의 결과가 나와야 함
- **명확성**: 각 단계는 모호하지 않고 명확해야 함
- **유한성**: 반드시 종료되어야 함
- **유효성**: 모든 명령은 실행 가능해야 함

## 2. 문제 해결 프로세스
1. **문제 정의**: 무엇을 해결해야 하는지 명확히 파악
2. **분해**: 큰 문제를 작은 단위로 나눔
3. **패턴 인식**: 유사한 문제의 해결 방식 찾기
4. **추상화**: 불필요한 정보는 제거하고 핵심 요소만 추출
5. **알고리즘 설계**: 단계별 절차 작성

## 3. 파이썬 개발 환경
- **IDLE**: 파이썬 설치 시 기본 제공되는 통합 개발 환경
- **PyCharm**: 강력한 기능을 가진 전문 IDE
- **Jupyter Notebook**: 데이터 분석 및 교육에 최적화된 대화형 환경
