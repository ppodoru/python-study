# 📂 Module 1.3: 기본 연산 (Basic Operations)

## 1. 산술 연산자
| 연산자 | 설명 | 예시 | 결과 |
| :---: | :--- | :--- | :--- |
| `+` | 더하기 | `5 + 2` | `7` |
| `-` | 빼기 | `5 - 2` | `3` |
| `*` | 곱하기 | `5 * 2` | `10` |
| `/` | 나누기 (실수) | `5 / 2` | `2.5` |
| `//` | 몫 | `5 // 2` | `2` |
| `%` | 나머지 | `5 % 2` | `1` |
| `**` | 거듭제곱 | `5 ** 2` | `25` |

## 2. 비교 연산자
- `==` (같음), `!=` (다름)
- `>` (큼), `<` (작음), `>=` (크거나 같음), `<=` (작거나 같음)

## 3. 논리 연산자
- `and`: 둘 다 참일 때 참
- `or`: 하나라도 참이면 참
- `not`: 참이면 거짓, 거짓이면 참
