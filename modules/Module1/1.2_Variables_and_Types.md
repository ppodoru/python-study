# 📂 Module 1.2: 변수와 기본 자료형 (Variables & Types)

## 1. 변수 (Variables)
데이터를 저장하는 메모리 공간의 이름입니다. 파이썬에서는 별도의 선언 없이 값을 할당하면 변수가 생성됩니다.

```python
name = "Ghent"
age = 2026
```

## 2. 기본 자료형
- **정수 (int)**: 소수점이 없는 숫자 (예: `10`, `-5`)
- **실수 (float)**: 소수점이 있는 숫자 (예: `3.14`, `-0.01`)
- **문자열 (str)**: 텍스트 데이터 (예: `"Hello"`, `'Python'`)
- **불리언 (bool)**: 참(`True`) 또는 거짓(`False`)

## 3. 자료형 확인 및 변환 (Type Casting)
```python
# 자료형 확인
print(type(10))  # <class 'int'>

# 자료형 변환
x = int("100")   # 문자열을 정수로
y = str(3.14)    # 실수를 문자열로
z = float(5)     # 정수를 실수를
```
