# 📂 Module 3.1: 함수 정의와 호출 (Functions)

## 1. 함수의 기본 구조
코드의 재사용성을 높이기 위해 특정 기능을 묶어 이름을 붙인 것입니다.

```python
def greet(name):
    """인사말을 반환하는 함수"""
    return f"Hello, {name}!"

message = greet("Ghent Student")
print(message)
```

## 2. 매개변수와 반환값
- **매개변수(Parameter)**: 함수에 전달하는 입력 값
- **반환값(Return value)**: 함수 실행 후 돌려주는 결과 값

## 3. 변수 범위 (Scope)
- **로컬(Local)**: 함수 내부에서만 유효
- **글로벌(Global)**: 프로그램 전체에서 유효
