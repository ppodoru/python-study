## 2. 파이썬 표준 라이브러리 활용
파이썬은 강력한 기본 모듈들을 제공합니다.

```python
import math
import random

print(math.sqrt(16))      # 제곱근: 4.0
print(random.randint(1, 10)) # 1~10 사이 랜덤 정수
```
