이 저장소는 겐트대학교 1학년 1학기 정보학(Informatics) 커리큘럼을 기반으로 파이썬을 학습하기 위한 공간입니다.

## 🎓 학습 목표
- 컴퓨팅 사고력을 기르고 파이썬의 핵심 문법을 마스터합니다.
- 데이터 처리, 파일 입출력, 그리고 정규 표현식을 통한 고급 데이터 정제 기법을 익힙니다.
- 객체 지향 프로그래밍(OOP) 및 데이터 시각화의 기초를 학습하여 실제 연구 및 프로젝트에 활용합니다.

## 📚 커리큘럼 요약
| 모듈 | 주제 | 주요 내용 |
| :--- | :--- | :--- |
| **Module 1** | Foundations | 알고리즘, 자료형, 기본 연산 |
| **Module 2** | Control Structures | 조건문, 반복문, 흐름 제어 |
| **Module 3** | Functions | 함수 정의, 변수 범위, 표준 라이브러리 |
| **Module 4** | Advanced Data | 리스트, 튜플, 딕셔너리, 집합 |
| **Module 5** | Strings & RegEx | 문자열 심화, 정규 표현식 패턴 매칭 |
| **Module 6** | I/O & Robustness | 파일 입출력, CSV 처리, 예외 처리 |
| **Module 7** | Advanced Topics | OOP 기초, Matplotlib 데이터 시각화 |
